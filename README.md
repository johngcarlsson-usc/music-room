# Class Music Room

Four browser music toys for a classroom, served with GitHub Pages:

- `monster-band/` – a monster band that plays a beat grid (built on Chrome Music Lab's Rhythm, Apache License 2.0)
- `kandinsky/` – Kandinsky Studio, draw lines and shapes and hear them played
- `song-maker/` – Class Song Maker, a melody and drum grid
- `hand-band/` – Hand Band, play music by moving your hands in front of a webcam (MediaPipe hand tracking, Apache License 2.0)

Each toy saves its settings in the browser that uses it.
